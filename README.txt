LEON SAI SONGS WEBSITE

1. Keep index.html and your video files in the same folder.
2. Add the first video as: video.b
3. Add the song video as: video.c
4. If GitHub Pages cannot play files with these names, rename them to:
   video.b.mp4 and video.c.mp4
   Then change the matching names inside index.html.
5. Upload index.html and the video files to GitHub Pages.

Buttons:
- Press out 1 or 2 times: start becomes big and “are you sure?” appears.
- Press out 3 times: returns to the first page.
- Press start: 3-second countdown, then song page.
- Press the arrow near out: returns to first page.
- Press “လုယွၼ်ႉၵဝ်” or any song button: opens video.c.
